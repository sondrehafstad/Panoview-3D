# 🌍 Panorama Viewer

A lightweight 360° panorama viewer built with React and Three.js.

Upload equirectangular panorama images and explore them in immersive 3D directly in the browser.

---

## ✨ Features

- 360° equirectangular panorama support
- Smooth mouse drag navigation
- Scroll wheel zoom
- Image gallery with preview thumbnails
- Adjustable mouse sensitivity
- Responsive layout
- Works both in browser and desktop build

---

## 🖼 How It Works

The viewer renders a sphere using Three.js and maps your panorama image onto the inside of the sphere.  
The camera is placed at the center, allowing you to look around freely.
